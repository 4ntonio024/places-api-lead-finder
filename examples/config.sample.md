# Sample Config

The **Config** tab drives the search. Column **A** = areas, column **C** = niche keywords. One value per row.

```
A (AREAS)                    C (NICHES / keywords)
---------------------------  ----------------------------
Cardedeu                     electricista
Llinars del Vallès           fontanero
Sant Antoni de Vilamajor     chapa y pintura
                             perruqueria
                             forn de pa
                             ...
```

## The keyword strategy (why sub-niches)

Generic categories ("workshops", "repairs") return broad, noisy results. **Sub-niche** keywords find real, specific businesses — and the smaller/older the trade, the more likely it has no website. Dig down:

- **Automotive:** `chapa y pintura`, `neumáticos`, `electricidad del automóvil`, `aire acondicionado coche`, `taller de motos`
- **Construction/reforms:** `pladur`, `carpintería de aluminio`, `fontanero`, `electricista`, `parquet`, `cerrajero`, `toldos`
- **Food/hospitality:** `forn de pa`, `carnicería`, `pastelería`, `frutería`, `pescadería`
- **Beauty/health:** `perruqueria`, `barbería`, `estética`, `fisioterapia`, `podología`
- **Shops/services:** `ferretería`, `floristería`, `tienda de ropa`, `reparación electrodomésticos`, `tintorería`

> Tip (ES/CA regions): list keywords in **both Spanish and Catalan** (`fontanero`/`lampista`, `carpintería`/`fusteria`) — local listings use either, and you don't want to miss businesses.

## Pinpointing a single business

To fetch one specific place, clear the keywords and put just its **exact name** as the only keyword (optionally set `MAX_PAGES = 1`). For a one-off Place ID lookup you don't even need this tool — use Google's free [Place ID Finder](https://developers.google.com/maps/documentation/javascript/examples/places-placeid-finder).
