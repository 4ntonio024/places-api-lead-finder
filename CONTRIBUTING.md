# Contributing

Thanks for your interest! This is a small, focused tool — issues and PRs are welcome.

## Ground rules

- **Code comments in English.** Docs (`README`, `docs/`) are bilingual EN/ES.
- **Never commit secrets.** Keep `API_KEY` as the `PASTE_YOUR_API_KEY_HERE` placeholder in `src/Code.gs`; real keys stay local (or in Script Properties).
- Keep the script dependency-free and runnable straight from the Apps Script editor.

## Proposing a change

1. Open an issue describing the use case before large changes.
2. For PRs: keep them small, match the existing style, and update the README/docs if behavior changes.

## Ideas to pick up

See the **Roadmap** in the [README](README.md) — `clasp` support, CSV export, scheduled triggers and locale-aware labels are all good first contributions.
